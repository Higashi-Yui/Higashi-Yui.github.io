# Lingkai Zhang — 简洁版个人科研主页

这一版刻意减少了页面数量和空白素材位。

## 页面
- `index.html`：首页
- `projects.html`：所有项目集中在一个页面
- `publications.html`：论文
- `profile.html`：教育、经历、技能、专利、荣誉、联系方式
- `files/Lingkai_Zhang_CV.pdf`：CV

## 设计原则
- 不再为每个项目做单独详情页
- 没有素材的项目只展示文字，不留空白占位框
- LTSFC、RoboCup、电赛使用现有真实图片/视频
- 日常开发素材作为一条工程实践记录
- 论文不提供 PDF 下载

## 部署
将本文件夹里的所有文件直接上传到 GitHub 仓库 `Higashi-Yui.github.io` 根目录。
Settings → Pages → Deploy from a branch → main → /(root)。
